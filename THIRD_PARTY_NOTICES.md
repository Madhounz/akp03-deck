## Device protocol references

The USB protocol was learned from these open source projects:

- mirajazz (MIT), https://github.com/4ndv/mirajazz
- soomfon, https://pypi.org/project/soomfon/
- codexdeck (MIT), https://github.com/sepivip/codexdeck

AKP03 Deck's driver is its own implementation that uses them as a reference for the protocol.
